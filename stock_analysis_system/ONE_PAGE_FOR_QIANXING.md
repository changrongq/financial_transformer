## 信号强度怎么看

| 大盘10日均 | 感觉 | 必须做的事 |
|---|---|---|
| **> +0.5%** | 强势 | HOLD，放心 |
| +0.1% ~ +0.5% | 温和涨 | HOLD |
| **-0.1% ~ +0.1%** | **抖（最烦）** | HOLD，但准备随时卖 |
| -0.5% ~ -0.1% | 温和跌 | CASH |
| **< -0.5%** | 明显跌 | CASH，**别抢反弹** |

**临界区（±0.1%）里 47% 的信号活不过 3 天。这很正常。**

## 必须接受的三个现实

**1. 会经常打脸**
一年 34 次切换，47% 的信号活不过 3 天。
```
08-31 卖 → 09-01 买
10-08 卖 → 10-09 买
```
**这是设计如此，不是坏了。**

**2. 会连续几年跑输**
上证50 逐年胜率只有 **48%**。一半的年份你会看着别人赚更多。

**3. 收益可能全靠一两年**
上证50 的 2015 年（+88.3pp）一年顶了 20 年。
**你需要在跑输的年份依然坚持。**

| 实际滑点 > 0.1% | 换标的或降仓 |
| **自己忍不住改规则** | **停手，别交易了** |

## 我们到底在赚什么钱

**A 股：隔夜亏钱（-14.9%/年），日内赚钱（+26.2%/年）**
**美股港股：完全相反**

原因大概率是 **T+1 制度**（买了当天不能卖，卖压堆到次日开盘）。

**我们赚的不是"预测涨跌"，是"不在下跌里亏"。**

**代价**：多数年份跑输、回撤反而略大。
