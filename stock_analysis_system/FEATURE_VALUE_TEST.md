> 2026-10-31

> 脚本：`test_feature_value.py` / `test_feature_value_strict.py` / `test_mean_reversion_signal.py`
> 结果：`results/feature_value*.json`、`results/mean_reversion_signal.json`

## 零、结论先说

**我们现有的 12 个技术特征，在扣除成本后，没有可靠的样本外增量信息。**

| 持有期 | 中位 IC | 显著标的 | 方向一致 | 滚动稳定 | 判定 |
|---|---:|---:|---:|---:|:--|
| 1 日 | +0.007 | 0/6 | 3正3负 | 1/6 | 无 |
| 5 日 | -0.006 | 0/6 | 3正3负 | 2/6 | 无 |
| 10 日 | -0.010 | 1/6 | 3正3负 | 0/6 | 无 |
| 20 日 | -0.069 | 2/6 | 1正5负 | 1/6 | 无 |

这个结论比 RL 那批实验的结论**更可靠**，因为：

- 用的不是 RL，而是最简单的 Ridge（alpha=10，强正则）
- 时间划分严格：train 60% / valid 20% / test 20%，不打乱
- 有**置换检验**（打乱标签 100~150 次）作为零分布
- 有**分块 bootstrap** 的 IC 置信区间
- 有**滚动窗口**检验时间稳定性
- 6 只标的独立重复

## 一、为什么必须先做这一步

知微的原话是关键：

> 「简单模型没有效果不证明一切非线性或序贯策略都无效，
>   但它能降低盲目追加 RL 训练的优先级。」

我们之前跑 5 次 RL 都失败（虽然失败是因为训练器 bug），
但如果**特征本身没有信息**，那修好训练器也没用 ——
再强的模型也只能拟合噪声。

**这一步的意义是：在花更多时间做 RL 之前，先确认有没有东西可学。**

---

## 二、设计

### 特征（12 个，全部 t 日收盘可得）

| 类别 | 特征 |
|---|---|
| 趋势 | `ret5` `ret10` `ret20` `ret60` |
| 波动 | `vol10` `vol60` `vol_ratio` |
| 择时 | `regime5` `regime10` `regime20` |
| 状态 | `down_run`（连续下跌天数）`dd_from_high`（距 120 日高点）|

`regime10` 就是现有择时策略用的骨架信号。

### 标签

未来 H 日累计收益：`close[t+H] / close[t] - 1`。

用累计收益而不是单日，因为单日信噪比约 0.05，几乎全是噪声；
而实际持有 H 天时，决策收益就是 H 日累计。

### 模型

| 模型 | 说明 |
|---|---|
| Ridge | 线性 + 强正则（alpha=10），最保守 |
| Logistic | 预测涨跌符号 |
| HistGradientBoosting | 非线性，但限深（3）、限轮（120）、限叶子（30）|

**如果最保守的 Ridge 都没有信息，不该先试复杂的。**

### 置换检验

打乱训练段标签 100~150 次，每次重训，得到测试 IC 的**零分布**。
真实 IC 落在零分布的哪个分位 → 就是 p 值。

这一步很重要，因为它告诉我们**IC 的噪声有多大**：
在 20 日持有期，6 只标的的零分布 std 在 **0.11 ~ 0.22** 之间。
也就是说，**IC = ±0.15 完全可能纯属偶然**。

## 三、结果

### 3.1 单标的详细（沪深300，H=20）

```
ridge     test: IC -0.1545   方向命中 0.464   分层差 -1.02%
logistic  test: IC -0.1328   方向命中 0.479   分层差 -1.36%
gbm       test: IC -0.0711   方向命中 0.491   分层差 -1.04%
[打乱标签] ridge test: IC +0.0935   方向命中 0.548   ← 应在 0.5 附近
```

注意：**打乱标签的模型也能得到 IC +0.09**。这就是噪声的量级。

### 3.2 多标的汇总

**H = 1 日**
```
中位 IC = +0.0070
显著标的数(p<0.05) = 0/6
方向: 正 3 / 负 3
滚动窗口 60% 同向 = 1/6
```

**H = 5 日**
```
中位 IC = -0.0060
显著标的数 = 0/6
方向: 正 3 / 负 3
滚动稳定 = 2/6
```

**H = 10 日**
```
中位 IC = -0.0095
显著标的数 = 1/6（仅创业板 p=0.02）
方向: 正 3 / 负 3
滚动稳定 = 0/6
```

**H = 20 日**
```
中位 IC = -0.0692
显著标的数 = 2/6
方向: 正 1 / 负 5
滚动稳定 = 1/6
```

### 3.3 唯一"显著"的创业板

创业板在 H=10（p=0.020）和 H=20（p=0.030）显著，IC 达 +0.23。

但：
- 6 只里只有 1 只
- 滚动窗口 5 个里只有 2~3 个同向
- 它在 H=1 和 H=5 的信号方向与 H=10/20 一致，但幅度小得多

**我们判断这是单一标的的偶然，不作为整体结论。**

## 四、追查：H=20 时 5/6 标的 IC 为负，是不是均值回归？

这是唯一看起来"有模式"的地方。如果真存在均值回归，
把预测取反做仓位就能赚钱。

### 4.1 二项检验

```
正 1 / 负 5 / 共 6
二项检验 p（负向）= 0.2188
```

**不显著。** 6 个样本里 5 个同向，这个概率有 22%，完全可能是偶然。

### 4.2 反向策略回测（扣 0.03%/边成本）

```
上证50     反向    +20.8%   持有    +22.0%   差    -1.2pp
沪深300    反向    +17.4%   持有    +44.7%   差   -27.3pp
中证500    反向     +3.7%   持有    +56.8%   差   -53.1pp
中证1000   反向     +9.6%   持有    +30.0%   差   -20.4pp
创业板      反向    -22.4%   持有    +76.0%   差   -98.4pp
科创50     反向    +17.2%   持有    +28.6%   差   -11.3pp

反向策略中位 +13.4%，跑赢持有 0/6
```

**一只都没跑赢。** 而且反向策略在每一只上都亏了（相对持有）。

### 4.3 分年度稳定性

```
2022: 中位 IC -0.0576  (1 只标的)
2023: 中位 IC -0.2703  (1 只标的)
2024: 中位 IC +0.2472  (5 只标的)   ← 方向反转
2025: 中位 IC -0.0126  (6 只标的)
2026: 中位 IC -0.0976  (6 只标的)
```

2023 是 -0.27，2024 是 +0.25。**IC 的符号在年份之间翻转**，
这是典型的无稳定信号特征。

## 五、一个必须说明的方法论问题

我们在第一版检验（`test_feature_value.py`）里，用**单次 IC** 判断，
差点得出错误结论。原因是：

- 单次 IC 的标准误太大（20 日持有期零分布 std 约 0.14）
- 6 只标的里出现 1~2 个 |IC| > 0.15 是**数学上的必然**

这正是知微提醒的**多重比较问题**。

所以第二版加了：
1. 置换检验的零分布（量化噪声量级）
2. 多标的的方向一致性检验
3. 滚动窗口的时间稳定性
4. 二项检验判断"同向"是否偶然

**只有三条判据全满足才算"有信息"，这大幅降低了假阳性。**

## 六、对下一步的影响

### 6.1 明确不做的事

| 不做 | 理由 |
|---|---|
| 用现有 12 个特征训练新的 RL | 特征无信息，模型再强也只是拟合噪声 |
| 用 regime10 当"已验证的骨架" | 它在这套特征里也没通过检验 |
| 只因为创业板显著就去优化创业板 | 6 选 1，是典型的选择性偏差 |

### 6.2 应该做的事

知微第四步说"如继续 RL，先做有限的仓位/换手决策"。
但在那之前，**应该先找有信息量的特征**。

我们现在的特征是纯价格派生的（收益、波动、regime）。
可能的信息源还没试过：

| 方向 | 数据是否已有 |
|---|---|
| 量价配合（成交额放大/缩小） | **已有**（刚修复的 `amount`）|
| 换手率（真实自由流通） | **已有**（`real_turnover_rate`，227 万条）|
| 市场宽度（涨跌家数比） | **已有**（`stock_data` 全市场）|
| 资金流（大单/小单） | 已有部分 |
| 北向资金 | 无 |
| 行业轮动 | 已有部分（`historical_daily` 277 只）|

**下一步建议：把成交额/换手率/市场宽度加进特征集，重跑这套检验。**
如果加了新特征还是无信息，那才可以说"这套数据里没有可学的东西"。

## 八、诚实说明的局限

1. **只测了 ETF 指数**，没测个股。个股噪声更大，结论可能不同但不乐观。
2. **特征集有限**：12 个纯价格特征，不含量价/换手/宽度。
3. **只测了线性 + 一个 GBM**，没测 LSTM/Transformer。但既然线性都无信息，
   先做非线性没有依据。
4. **成本只算了 0.03%/边**，实盘可能更高，结论只会更差。
5. **2012-2026 是单一样本**，无法排除"这段时间特别难做"。
