## 一、问题比知微指出的更严重

知微指出：`close × vol` 因 `vol` 单位是"手"而含义不明。

**实际诊断发现：`stock_data.成交量` 单位有三段不一致。**

### 证据：000001（平安银行）2025-04 ~ 2025-12

```
2025-04-28   收盘 11.00   成交量      642,018   ← 手
2025-04-29   收盘 10.65   成交量   64,904,494   ← 突然 ×101！
2025-05-06   收盘 10.63   成交量   85,467,127
...
2025-10-31   收盘 11.32   成交量      970,193   ← 恢复到"手"
2025-11-03   收盘 11.43   成交量      952,326
```

**从 2025-04-29 到 2025-10-31，成交量被乘了 100 倍（单位从"手"变成"股"）。**

### 中位数比值验证

比较 2025-03-31 和 2025-05-06 同一批股票的成交量：

| 指标 | 值 |
|---|---|
| 比值中位数 | **110.00** |
| 比值均值 | 152.48 |

**确认是 ×100 的单位切换。**

### 这会造成的后果

| 现象 | 原因 |
|---|---|
| 2025-05~10 "满足 5000万门槛"占 67-72% | 成交量×100 → `close×vol` 虚高 100 倍 |
| 其他月份只有 0.6% | 单位正常 |

**"高换手日内策略"的所有结论，都建立在这段被污染的成交量上。**

## 二、修复方案与执行

### 数据源单位确认

`tushare.daily` 返回：
- `vol`：单位 = **手**（1 手 = 100 股）
- `amount`：单位 = **千元**

验证（000001，2024-10-14）：
```
tushare: vol=2,400,595.09(手)  amount=2,881,934.272(千元)
  → 成交量 = 240,059,509 股
  → 成交额 = 2,881,934,272 元
数据库:  成交量=240,059,509   成交额=2,881,934,272
匹配: OK / OK
```

### 修复脚本

`scripts/repair_amount_data.py`

- 自动识别需修复的交易日（成交额缺失 或 成交量量级异常）
- 按 `trade_date` 批量拉全市场（1 次 API 调用/天）
- 统一写入：**成交量存"股"，成交额存"元"**

### 执行结果

| 项目 | 值 |
|---|---|
| 待修复交易日 | 346 |
| 修复行数 | **1,870,309 行** |
| 失败 | 0 |

### 修复后校验

**单位统一验证**（用 `成交额/收盘价` 反推真实成交量 vs 库存储）：

| 月份 | 成交量 / 反推值（中位） | 判定 |
|---|---|---|
| 2024-10 ~ 2026-10 | **全部 1.00** | ✅ 单位统一为"股" |

**成交额覆盖率**：

| 时期 | 覆盖率 |
|---|---|
| 2024-10 ~ 2025-08 | 95.3-95.5% |
| 2025-09 ~ 2026-03 | 98.3-99.9% |
| 2026-04 ~ 2026-10 | 100% |

> 早期 95% 是因为部分股票停牌/新股无数据，属正常。

## 三、修复后的真实结论

### 高换手日内策略（用干净数据重算）

| 分组 | 日均日内 | 日均隔夜 | 样本(股票日) |
|---|---|---|---|
| 换手率最高 10% | +29.38bp | -35.77bp | 357 |
| **换手率最高 20%** | **+27.35bp** | -33.04bp | 693 |
| 换手率最高 30% | +23.85bp | -27.49bp | 1026 |
| 全市场 | +11.89bp | -16.99bp | 3030 |

### 成本敏感性

| 单边成本 | 每日净 | 年化 | 结论 |
|---|---|---|---|
| 0.00% | +27.35bp | +66.7% | 赚 |
| 0.05% | +17.35bp | +42.3% | 赚 |
| **0.10%** | **+7.35bp** | **+17.9%** | **赚** |
| **0.15%** | **-2.65bp** | **-6.5%** | **亏** |
| 0.20% | -12.65bp | -30.9% | 亏 |

**盈亏平衡单边成本：0.137%**

**A 股个股实际单边成本：0.10%~0.20%**（印花税0.05% + 佣金0.05% + 滑点）

**→ 临界点 0.137% 正好落在成本区间中间：边缘，不可靠。**

### 稳定性（前后半段）

| 时段 | 日内收益 |
|---|---|
| 前半段 | +31.90bp/天 |
| 后半段 | +22.80bp/天 |

**两段都为正，但衰减 29%。**

### 可交易性

在 448 个交易日中，**16 天（3.6%）**该组有超过 2% 的股票开盘向上跳空 ≥ +9.5%（近似涨停，买不进）。
