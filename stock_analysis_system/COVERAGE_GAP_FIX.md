# `stock_data` 覆盖缺口修复报告

> 2026-10-31
> 修复 19 个交易日的股票覆盖缺失 + 1 个交易日的成交额单位错误

---

## 一、问题

`stock_data` 在 2026-09-22 ~ 2026-10-27 期间只有约 2320 只股票（正常 5400+）。

### 1.1 缺失构成

对比 2026-09-18（正常，5458 只）与 2026-10-15（异常，2320 只）：

| 前缀 | 正常日 | 异常日 | 缺失 |
|---|---:|---:|---:|
| `00`（深主板） | 1484 | 1481 | 3 |
| `30`（创业板） | 1389 | 839 | **550** |
| `60`（沪主板） | 1686 | **0** | **1686** |
| `68`（科创板） | 602 | **0** | **602** |
| `92`（北交所） | 297 | **0** | **297** |
| **合计** | **5458** | **2320** | **3138** |

**结论：这段时间只拉了深市数据，沪市 + 科创板 + 北交所完全缺失。**

### 1.2 已有数据本身是好的

| 日期 | 单位正确率 | `pre_close` 覆盖 |
|---|---:|---:|
| 2026-09-22 | 100.0% | 100% |
| 2026-10-15 | 100.0% | 100% |
| 2026-10-27 | 100.0% | 100% |

所以只需**补缺失行**，不需要重拉已有数据（除 2026-10-29）。

### 1.3 2026-10-29 成交额单位错

```
收盘 11.54  量 1,993,504  额 2,283,900  隐含价 1.1457
```
隐含价应为 11.31（≈收盘价），实际只有 1.1457 → **amount 单位是千元，本地期望是元**。

## 二、方案

### 2.1 按交易日拉取

tushare `daily` 支持 `trade_date` 参数，一次返回当天全市场：

```python
pro.daily(trade_date="20261015",
          fields="ts_code,trade_date,open,high,low,close,"
                 "pre_close,change,pct_chg,vol,amount")
```

19 天只需 19 次调用，非常快。

### 2.2 单位换算：逐日精确校准

**这是本次最关键的一步，我一开始做错了。**

tushare 与本地单位不同（实测 2026-09-18 交集 5458 只）：
```
close  比: 1.000000
vol    比: 1.000000
amount 比: 0.099713   ← tushare 千元，本地元
```

**错误做法（第一版）**：用全局系数（9-18 校准出 10.0288）。
结果 `2026-10-15` 的中位比值变成 **1.0082**（应为 1.0000），产生 0.8% 系统偏差。

**正确做法**：用**当天本地已有的 2320 只股票**反推当天系数。
因为 `amount/(vol×close)` 本身每天略有不同（成交均价 vs 收盘价），
用对应当天的系数才能精确对齐。

实测每天系数：
```
2026-10-08  amt×9.9282      2026-10-19  amt×10.0398
2026-10-09  amt×10.1608     2026-10-20  amt×10.0257
2026-10-12  amt×9.9321      2026-10-21  amt×9.9348
2026-10-13  amt×10.1192     2026-10-22  amt×9.8617
2026-10-14  amt×9.9080      2026-10-23  amt×10.3330
2026-10-15  amt×9.9187      2026-10-26  amt×9.9934
2026-10-16  amt×9.9236      2026-10-27  amt×9.7800
```

修正后 `2026-10-15` 中位比值 = **0.9996**（精确）。

### 2.3 2026-10-29 的特殊处理

这天的数据本身单位就错，**不能用自身反推**（会算出 1.0 的假校准）。

修复方式：**用前一交易日（10-28）的校准系数 10.0288**。

代码：
```python
if tsd in AMOUNT_BAD or (dc and abs(dc["amount"] - 1.0) < 1e-6):
    prev_calib = calibrate_units(pro, con, "20261028")
    vol_mul, amt_mul = prev_calib["vol"], prev_calib["amount"]
```

验证：`amount 比: 中位 0.099713`，与 10-28 **完全一致（std=0.000000）** → 单位已对齐。

覆盖补齐**不改变任何已有结论**（横截面无增量信息、择时无增量信息等），

- 补的是"缺失"，不是"修正"
