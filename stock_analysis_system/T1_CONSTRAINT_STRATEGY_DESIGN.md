# T+1 约束下的策略设计：为什么"每天做T"是死的，什么才能活？

> 2026-10-29
> 这是隔夜/日内三篇研究的**实践篇**：
> 知道了"隔夜负、日内正"之后，在 T+1 制度下到底能做什么？

---

## 一、先澄清一个致命的误解

### 回测里的"日内收益"**不能交易**

我们之前的分析说：
- 隔夜（昨收→今开）：**-10.76%/年**
- 日内（今开→今收）：**+15.92%/年**

看起来"只做日内"就能赚 15.92%。

**但 T+1 制度下，"今天开盘买、今天收盘卖"是违规的。**

那这个 +15.92% 到底是什么？**它只是一个数学分解，不是可执行的策略。**

### 四种持有方式的真实收益（510300，14.4年）

| 持有方式 | 含隔夜 | 含日内 | T+1 可行 | 年化 |
|---|---|---|---|---|
| T开盘买 → T收盘卖（纯日内） | ✗ | ✓ | **❌ 违规** | +15.76% |
| T收盘买 → T+1开盘卖（纯隔夜） | ✓ | ✗ | ✓ | **-10.76%** |
| **T开盘买 → T+1开盘卖**（最短可交易周期） | ✓ | ✓ | ✓ | **+3.15%** |
| T开盘买 → 一直持有 | ✓ | ✓ | ✓ | +3.20% |

**T+1 下最短可交易周期是"T开盘买 → T+1开盘卖"，收益 +3.15%——几乎等于买入持有（+3.20%）。**

### 成本直接杀死了这条路

| 单边成本 | T开盘买→T+1开盘卖 年化 |
|---|---|
| 0%（毛） | +3.15% |
| 0.05% | **-19.19%** |
| 0.10% | -36.71% |
| 0.20% | -61.20% |

**盈亏平衡成本：0.0065%。**

ETF 实际成本 0.03-0.05% —— **比临界点高 5-8 倍。**

> **结论：高频"做T"在 T+1 + ETF 成本结构下，数学上就是死的。RL 再聪明也救不了。**

---

## 二、为什么"每天交易"必然失败（一般性规律）

设：
- 每日毛收益 = μ
- 每日交易成本 = 2c（买卖各一次）
- 年化净 ≈ 244 × (μ - 2c)

**关键洞察**：高频策略的收益，永远要被"每日 2c"扣一次。所以：

**能不能做，只取决于 μ 和 2c 的比较，和策略多聪明无关。**

| 策略 | μ（每日毛） | 2c（每日成本） | 结论 |
|---|---|---|---|
| 全市场等权日内 | +15.75bp | 20-40bp（个股） | ❌ |
| 高换手股票日内 | +22.73bp | 20-40bp | ❌ 边缘 |
| ETF 日内 | +15.76bp | 6-10bp | ⚠️ 极边缘 |
| **T开盘买→T+1开卖** | **+1.3bp** | 6-10bp | ❌ 差太远 |

> **注意最后一行**：+3.15%/年是 244 天累积的结果，折算到每天只有约 1.3bp。这远低于任何成本。

**所以"缩短持有期"不是优化方向，是自杀方向。**

## 三、什么才能活？降低交易频率

真正有效的方向是：**提高单次交易的收益，降低交易次数。**

### 择时（已验证，14年）

- 只在 HOLD 日持仓，交易次数 **34次/年**（不是 244 次）
- 14 年：**+160.1% vs 买入持有 +57.9%**（19/20 参数胜）
- 回撤 -26.5% vs -46.3%

**为什么它有效：**
1. 交易次数少 → 成本低（14年累计拖累约 24pp，可接受）
2. 只在趋势向上时持仓 → 避开下跌段
3. T+1 开盘执行 → 吃到日内收益（+15.92% 的那部分）

### RL v4：可变持有期（本次实验）

**设计思路**：让 RL 决定"持有多久"，而不是"今天仓位多少"。

动作空间：
```
0  = 空仓
1  = 持有 1 个交易日（明天开盘买，后天开盘卖）
2  = 持有 2 个交易日
3  = 持有 3 个交易日
5  = 持有 5 个交易日
10 = 持有 10 个交易日
```

**关键约束**：一旦决定持有 N 天，中间 N-1 天**不再决策**（不产生成本）。

**理论优势**：如果 RL 学会"在趋势好时持有 10 天、趋势差时空仓"，平均持仓期会拉长，交易成本自然下降。

**这是 RL 在这个问题里唯一合理的用法**——它优化的是**持有期**，不是**高频进出**。

## 四、RL 的四次尝试（完整记录）

| 版本 | 设计 | 结果 | 失败/成功原因 |
|---|---|---|---|
| v1 | 5档仓位（0/25/50/75/100%），奖励=超额 | ❌ 退化为恒定50% | 奖励 `(p-1)×r` 期望≈0，梯度消失 |
| v2 | 同上，奖励改为净收益 | ⚠️ 62%胜率但方差19.5pp | 数据仅292天，过拟合 |
| v3 | 4种时间点（空仓/隔夜/日内/全天） | ⚠️ 学到"日内仓40%+空仓58%" | 自己发现了隔夜负规律，但收益靠运气 |
| **v4** | **可变持有期（0/1/2/3/5/10日）** | 见结果 | 设计最贴合 T+1 约束 |

### v3 的意外收获

RL v3 的动作分布是：
```
空仓    58.3%
隔夜仓   1.1%
日内仓  40.0%
全天仓   0.5%
```

**它几乎不用"隔夜仓"和"全天仓"，只用"空仓"和"日内仓"。**

**这独立复现了我们手动分析出的结论**——虽然 RL 的收益数字不可靠，但它"学到了正确的方向"。

## 六、我的判断

### 短期（现在能做的）

✅ **择时（14年验证，19/20参数胜）** —— 这是唯一可执行的
✅ **RL 可变持有期** —— 正在测试，如果能稳定跑赢"固定持有 N 天"，就有价值
❌ **高频做T** —— 数学上不可行，不要碰

### 中期（1-2年）

⏳ **积累分钟数据** —— 每天跑采集脚本
⏳ **如果积分/资金到位** —— 直接拿历史分钟数据

### 长期（要警惕的）

⚠️ **隔夜效应在衰减**：2006-2010 是 -16.5%，2021-2026 只剩 -11.3%
⚠️ **T+0 制度风险**：一旦推出，整个"隔夜负"逻辑失效

## 八、一句话总结

**T+1 制度禁止当天买卖，所以"每天做T"在数学上就被成本杀死了。真正能活的是"降低交易频率 + 吃日内收益"——这恰好就是择时策略。RL 如果有用，也只能用来优化"持有多久"，而不是"多久进出一次"。**
