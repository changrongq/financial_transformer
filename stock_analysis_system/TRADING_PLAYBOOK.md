## 一、先想清楚：我们赚的是什么钱

### 一句话

**我们赚的是"市场恐慌之后、趋势恢复的那一段"，不是"预测明天涨跌"。**

### 具体是什么

研究里发现了一个 A 股独有的现象（`GLOBAL_OVERNIGHT_COMPARISON.md`）：

| | A股 | 美股 | 港股 |
|---|---|---|---|
| 隔夜（昨收→今开） | **-14.9%** | +6.1% | +4.6% |
| 日内（今开→今收） | **+26.2%** | +2.3% | -1.8% |

**A 股的钱几乎全在"日内"，隔夜是亏的。** 这大概率是 T+1 制度造成的——当天买了不能卖，卖压全堆到第二天开盘。

但**我们拿不到"每天开盘买、收盘卖"这笔钱**——T+1 不允许，而且每天交易的成本（临界点 0.032%）会吃光它。

**我们能拿到的，只有一部分：**

```
大盘连跌 → 空仓（避开继续跌）
大盘回稳 → 开盘买入 → 持有到下一个卖出信号
```

**这就是择时。它赚的是"不在下跌里亏"的钱，不是"抓住每次上涨"的钱。**

### 必须接受的代价（v7.0，知微修正后）

| 事实 | 数据 |
|---|---|
| 多数标的会跑输买入持有 | 收益仅 **3/6** 跑赢 |
| 主标的（510300）明确跑输 | **+45.6% vs +98.6%，劣势 -53.1pp** |
| 夏普多数变差 | 4/6 改善，中位数仅 **+0.02** |
| 唯一明确的亮点 | 回撤 **6/6** 全部改善，中位数 **+14.0pp** |
| 参数不稳健 | 20组参数 × 6标的，仅 **53.3%** 跑赢 |
| 滑点极度敏感 | 必须 **<0.05%**，否则优势消失 |

**结论：这不是一个"稳赢"策略。它是一个"用收益换回撤"的策略。**
**如果你要的是更高的绝对收益，直接买入持有；如果你无法承受 -45% 级别的回撤，这个策略能把它压到 -36%。**

## 二、每天做什么（10 分钟）

### 收盘后（15:00 之后）

```powershell
cd d:\qcr\Stock\stock_analysis_system
.venv\Scripts\python.exe experiments\financial_transformer\daily_regime_timing_signal.py
```

**脚本会自动先拉当天数据**（首次跑可能慢 10-30 秒），然后计算信号。

只看两个数：

```
日期: 2026-10-29                ← 先确认是今天！
大盘近 10 日均收益: -1.101%      ← 看这个
当日市场收益: -2.621%

```

### 重要：先确认日期是对的

**如果输出的日期不是今天**，说明数据没拉到。可能原因：

| 原因 | 怎么办 |
|---|---|
| 还没到收盘（15:00 前） | 等收盘后再跑 |
| 今天不是交易日 | 用上一个交易日的信号 |
| tushare 数据延迟 | 等半小时再试，或手动刷新 |

**绝对不要用旧日期的信号交易。**

```powershell
# 检查数据新鲜度（不拉取）
.venv\Scripts\python.exe scripts\refresh_market_data.py --check-only

# 手动刷新
.venv\Scripts\python.exe scripts\refresh_market_data.py

# 跳过刷新直接算（数据已确认最新时用）
.venv\Scripts\python.exe experiments\financial_transformer\daily_regime_timing_signal.py --no-refresh
```

### 记录到你的表里

| 日期 | 大盘10日均 | 信号 | 我的仓位 | 备注 |
|---|---|---|---|---|
| 2026-10-28 | -1.125% | CASH | 0% | 卖出510300 |

**每天记一行。** 一个月后你会看到自己有没有按纪律执行。

### 第二天开盘（9:30）

| 信号 | 动作 |
|---|---|
| **HOLD** | 如果有仓位→不动；如果空仓→**开盘买入** 510300 |
| **CASH** | 如果有仓位→**开盘全部卖出**；如果空仓→不动 |

**开盘那几分钟就要做完，不要等。**

原因：研究显示策略的收益来自"跟着日内走"，拖到下午再操作，收益会大幅缩水。

## 三、怎么读信号（关键判断）

### 信号强度分级

`大盘10日均收益` 这个数字，不只是正负，**离 0 多远也很重要**：

| 数值范围 | 含义 | 建议动作 |
|---|---|---|
| **> +0.5%** | 强势上涨 | HOLD，放心持有 |
| +0.1% ~ +0.5% | 温和上涨 | HOLD |
| **-0.1% ~ +0.1%** | **临界区（最容易抖动）** | HOLD，但做好随时卖的准备 |
| -0.5% ~ -0.1% | 温和下跌 | CASH |
| **< -0.5%** | 明显下跌 | CASH，不要抢反弹 |

**临界区（-0.1% ~ +0.1%）是最难受的。** 实测 47.4% 的信号段活不过 3 天，大部分就发生在这一带。

### 什么时候信号"可信"，什么时候"可能骗人"

**可信度高的 CASH 信号：**
- 大盘10日均 < -0.5%
- 当天大盘跌幅 > 2%
- 连续 3 天以上下跌

**可信度高的 HOLD 信号：**
- 大盘10日均 > +0.5%
- 连续 5 天以上在 0 以上

**容易骗人的：**
- 大盘10日均在 ±0.1% 之间来回穿
- 刚从 CASH 转 HOLD，但只转了一天

**但注意：即使不可信，也要按信号做。** 我们测过，加"确认期"会让收益变差（见下）。

### 不要做的事

| ❌ 不要 | 为什么 |
|---|---|
| 盘中看盘、手动干预 | 会破坏纪律，且盘中数据不完整 |
| 看到 CASH 觉得"跌得差不多了，先不卖" | 2015、2022 都是这样亏的 |
| 看到 HOLD 觉得"涨太多了，先跑" | 你会错过主升段 |
| 用"确认期"或"死区"过滤抖动 | 实测收益会下降（滤掉抖动也滤掉了对的信号） |

## 四、交易标的选择

### 结论：只做 510300，最多加 512100

那些"中证500/创业板/上证50"的数字，是**为了验证规律是否普适**，不是让你都买。

### 主标的：510300 沪深300ETF

| 项目 | 内容 |
|---|---|
| 代码 | **510300** |
| 日均成交额 | 数十亿（最深） |
| 实际买卖价差 | ≈0.024%（0.001元/4.1元） |
| 历史 | 14.4 年（2012 起） |
| 严格 T+1 | **+45.6% vs 买入持有 +98.6%（劣势 -53.1pp）** |
| 回撤 | **-36.3% vs 买入持有 -45.5%（改善 9.2pp）** |
| 夏普 | **0.25 vs 0.33（跑输）** |

**为什么选它：流动性最好，滑点能压到 0.03% 以内，这是它最关键的优势。**

### 辅助（可选）：512100 中证1000ETF

| 项目 | 内容 |
|---|---|
| 代码 | **512100** |
| 历史 | 9.9 年 |
| 严格 T+1 | **+75.4% vs 买入持有 -3.7%（优势 +79.2pp）** |
| 回撤 | **-26.1% vs -51.0%（改善 24.9pp）** |
| 夏普 | 0.43 vs 0.11 |
| 逐年胜率 | **7/10 = 70%** |
| 滑点 0.1% 时 | **+56.5% 仍远超买入持有** ✅ |

**优势：容错空间更大（0.1% 滑点下还能赢），逐年胜率更高（70%）。**
**劣势：流动性不如 300，滑点可能在 0.05-0.08%。**

### 不建议用的标的

| 标的 | 为什么不用 |
|---|---|
| 510050 上证50ETF | **0.1% 滑点下跑输**（+94.2% vs +346.7%）；**逐年胜率仅 38%** |
| 159915 创业板ETF | 0.1% 滑点下跑输（+212.1% vs +233.8%）；回撤 -53.6%，太难拿 |
| 588000 科创50ETF | **只有 5.9 年样本**，太短，不能确认规律成立 |
| 510500 中证500ETF | 数据不错，但流动性不如 300，且优势主要来自"买入持有也很差" |

### 完整对比表（v7.0，知微修正后）

| 标的 | 年数 | 买入持有 | 严格T+1 | 优势 | 回撤改善 | 滑点0.1%下 |
|---|---|---|---|---|---|---|
| 上证50ETF | 20.5 | +349.6% | +156.8% | **-192.8pp** | +17.2pp | 跑输 |
| **沪深300ETF** | 14.4 | +98.6% | +45.6% | **-53.1pp** | **+9.2pp** | 跑输 |
| 中证500ETF | 13.6 | +129.8% | +674.8% | +545.0pp | +10.9pp | 跑赢 |
| **中证1000ETF** | 9.9 | -3.7% | +75.4% | +79.2pp | **+24.9pp** | 跑赢（0.2%时输） |
| 创业板ETF | 14.8 | +229.9% | +215.3% | -14.6pp | +6.0pp | 跑输 |

### 三条铁律

**1. 不要同时买多个。**
信号是同一个（大盘10日均），同时买 3 只 ETF 等于同一笔交易做了 3 次，**只增加成本，不分散风险**。

**2. 如果只用一只，选 510300。**
它在"滑点"和"流动性"上是最安全的，虽然测试中优势只有 +17pp，但**那 0.1% 的滑点假设对它过于悲观**（实际 0.024%）。

**3. 如果要做第二只，选 512100。**
它的容错空间更大（0.1% 滑点仍大幅跑赢），逐年胜率 70%。

**4. 上证50 千万别用。**
不管它历史收益多高（+280.6%），**0.1% 滑点就跑输，逐年胜率 38%** —— 这是个看起来很美但实际拿不住的标的。

## 五、仓位管理

### 起步阶段（头 1 个月）

```
信号 HOLD → 20-30% 仓位
信号 CASH → 0%
```

**目标不是赚钱，是验证你能不能做到"开盘立刻执行"。**

### 验证阶段（1-3 个月）

如果做到了：
```
信号 HOLD → 40-50% 仓位
信号 CASH → 0%
```

### 稳定阶段（3 个月后）

```
信号 HOLD → 最多 70% 仓位
信号 CASH → 0%
```

**为什么不满仓？**

因为逐年胜率只有 48-70%，靠少数极端年份赚钱。**满仓意味着你要承受 -74% 的回撤（上证50ETF 数据），多数人扛不住。**

### 空仓时钱放哪

货币基金（如 511990 华宝添益、511880 银华日利），T+0 可赎回，年化约 1.5-2%。

**不要躺在券商账户里吃活期利息。**

## 七、什么时候该停下来

### 立刻检查的红色信号

| 现象 | 可能原因 | 怎么办 |
|---|---|---|
| 连续 10 次信号都错 | 市场 regime 变了 | 暂停，重跑回测 |
| 大盘10日均长期在 ±0.1% | 震荡市，策略失效 | 降仓位到 30% |
| 实际滑点 > 0.1% | 流动性变差 | 换标的或降仓位 |
| 自己忍不住改规则 | 心态问题 | **停下来，别再交易** |

### 策略失效的长期风险

**最需要警惕的两件事：**

**1. T+0 制度推出**
我们的收益来自 T+1 制度（隔夜亏、日内赚）。如果哪天 A 股推出 T+0，这个效应会大幅减弱。

**2. 效应在衰减**
| 时段 | 沪深300 隔夜年化 |
|---|---|
| 2006-2010 | -16.5% |
| 2011-2015 | -18.5% |
| 2016-2020 | -13.8% |
| 2021-2026 | **-11.3%** |

**20 年衰减了 1/3。** 按这个速度，10-15 年后可能就没了。

**建议：每年重跑一次回测，看效应是否还在。**

## 八、心态：这是最难的部分

### 三个必须接受的现实

**1. 你会经常"打脸"**

实测：每年 34 次切换，47.4% 的信号段活不过 3 天。

```
2026-08-31 卖出 → 09-01 买入   （隔天买回）
2026-10-08 卖出 → 10-09 买入   （隔天买回）
```

**这不是策略坏了，这是设计如此。**

**2. 你会连续几年跑输**

上证50ETF 逐年胜率 **38.1%（8/21 年）**。意味着**大多数年份你会看着买入持有的人赚得更多**。

**3. 你的收益可能全靠个别年份**

上证50ETF 的最大贡献年是 **2008 年（+22.1pp）**，其次 2022 年（+18.6pp）。
但这两年之后，紧接着的 2009（-20.2pp）和 2023（+2.0pp）都会让你怀疑人生。

**你需要在 2007 年跑输 96.8pp、2025 年跑输 17.4pp 的年份，依然坚持。**

### 三句话记住

1. **按信号做，不按感觉做。** 你的感觉在 2015、2022 都会让你亏钱。
2. **看年度，不看单笔。** 单笔"打脸"亏损没有意义。
3. **受不了就跑。** 如果心态崩了，最好的选择是停手，而不是改规则。

## 九、这套东西的边界（诚实的总结）

### 我们确实搞清楚了的

| 结论 | 证据 |
|---|---|
| 个股动量在全市场无效 | -70.1% vs 买入持有 +18.9% |
| A股隔夜亏、日内赚，且是全球独有 | 11/11 标的，美股港股相反 |
| 原因是 T+1 制度 | 换手率越高效应越强（5倍差距） |
| 高频日内交易不可行 | 临界成本 0.032% vs 实际 0.03-0.05% |
| RL 学不会日频决策 | 五次尝试，熵始终 1.098≈随机 |
| **择时：收益 3/6 胜、回撤 6/6 胜** | 知微修正后重算 |
| **主标的 510300 收益跑输 53pp** | 只有回撤改善 |
| **参数稳健 53.3%，滑点需 <0.05%** | 不是稳赢策略 |

### 我们还没搞清楚的

| 问题 | 现状 |
|---|---|
| 未来还会有效多久 | 效应每年衰减约 1.5% |
| 极端年份依赖有多严重 | 2015 贡献了上证50 的大部分收益 |
| 开盘几分钟的真实成交价 | 缺分钟数据，只能等积累 |
| 有没有比 10 日均线更好的信号 | 没系统找过 |

## 最后一句话

**我们不是找到了一个"赚钱的公式"，而是找到了一条"知道自己赚什么钱、也知道会怎么亏"的路。**

这一年我们走了五条路，每条都看到了新的边界：

| 走过的路 | 看到的边界 |
|---|---|
| 个股动量 | 在全市场是 -70.1%，只在特定行业池有效 |
| 择时（初版） | 有未来函数，数字虚高 |
| 择时（2年数据） | 样本太短，结论不可靠 |
| 择时（14年数据） | 口径违规 + 数据未复权 |
| **择时（严格T+1）** | **能用，但逐年胜率仅48-70%，靠极端年份** |

**每一次发现边界，都不是白走——它让我们知道这条路能走多远。**

知道会怎么亏，比知道怎么赚更重要。
