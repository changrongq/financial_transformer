## 请先读这一段：结论又变了，暂缓实盘

**2026-10-31，千年舟的知微复核了我们的统一回测引擎，发现 3 处记账错误。**

| # | 错误 | 影响 |
|---|---|---|
| 1 | **卖出日漏记隔夜收益** | 卖出日无论涨跌，净值都不动 |
| 2 | 夏普用了净值绝对变化，不是收益率 | 所有夏普数字作废 |
| 3 | 回撤的累计最高值没包含初始资本 1 | 所有回撤数字被低估 |

**三处全部确认成立。修正后重算，结论大幅变化：**

| 指标 | 修正前 | **修正后** |
|---|---|---|
| 收益跑赢标的数 | 5/6 | **3/6** |
| **沪深300ETF（主标的）** | +115.7%（赢） | **+45.6%（输 53pp）** |
| 沪深300 夏普 | 0.31 vs 0.19（赢） | **0.25 vs 0.33（输）** |
| 沪深300 回撤 | -30.1% vs -45.5% | -36.3% vs -45.5%（**改善 9.2pp**） |
| 参数网格胜率 | 54.2% | **53.3%** |
| 滑点 0.05% 仍赢 | 4/6 | **3/6** |

**最讽刺的一点**：我们自己的核心发现是"A 股隔夜平均 -14.9%/年"，却**在回测里把卖出日的隔夜收益当成 0**。一边论证隔夜亏钱，一边记账时当它不存在。

**现在唯一还站得住的亮点**：6/6 标的回撤改善（中位数 +14.0pp）。

**还有一个心理准备**：上证50ETF 逐年胜率只有 **38.1%（8/21 年）**，最大贡献年是 2008 年（+22.1pp）与 2022 年（+18.6pp），而 2007 年单年跑输 **96.8pp**。也就是说，**大多数年份你会看着买入持有的人赚得更多**。

## 第一部分：ETF 择时（严格 T+1，全部修正后）

### 1.1 规则

```
大盘（全市场等权）最近 10 个交易日的平均日收益

  < 0   ->  CASH（卖出，空仓）
```

**执行铁律**：T 日 15:00 收盘后看信号 → T+1 日 9:30 开盘立即执行。

## 第四部分：什么不要做

| 别做的事 | 为什么不行 | 证据 |
|---|---|---|
| 用模型预测个股短期涨跌 | 输出塌缩，AUC 0.435 | 五轮全失败 |
| 反向使用模型信号 | 输出标准差 1e-6，纯噪声 | signal_score 极差 1e-6 |
| 用日历效应做交易 | 逐年分解 5/7 年负 | `CALENDAR_FACTOR_REPORT.md` |
| 用台风模型选股 | persistence Spearman **-0.163** | `TYPHOON_BACKTEST_NOTE.md` |
| 用强化学习调仓位 | 五次全失败，熵 1.098≈随机 | `GROKKING_VS_NOISE.md` |
| 跟着情绪操作 | 亏损后14%，盈利后64% | +95.4% vs 规则 +822.4% |
| 个股动量选股 | 全市场 -70.1% | `validate_full_market_momentum.py` |
| 高频做 T | 盈亏平衡 0.032%，实际 0.03-0.05% | `test_intraday_only_strategy.py` |

### RL 五次失败记录

| 版本 | 设计 | 结果 |
|---|---|---|
| v1 | 5档仓位，奖励=超额 | 恒定50%（奖励期望≈0） |
| v2 | 改净收益奖励 | 62%胜率但方差19.5pp |
| v3 | 4种时间点 | 学到方向但收益靠运气 |
| v4 | 可变持有期 | 0/5，训练集也负 |
| v5 | 择时骨架+3动作 | 1/3，方差99pp，熵 1.098 |

**结论：日频单资产决策不适合 RL（信噪比 0.05，样本仅 3443 天）。**

## 第五部分：信号和直觉冲突时

1. 信号说 CASH 但你觉得会涨 → 按信号走
2. 信号说 HOLD 但你觉得危险 → 按信号走，可减半仓
3. 动量清单里的股票你觉得垃圾 → 你的判断对，别买
4. 连续错 3 次想放弃 → 切换准确率 43%，连错 3 次是常态
5. 某个月大幅亏损 → 先确认执行偏差

**最重要的教训：我们修正了七次。前六次都是"好消息之后发现是假的"。第七次发现的错误最讽刺——我们一边论证"A股隔夜亏钱"，一边在回测里把卖出日的隔夜收益当 0。**
