## ⛔ 先读这一段：v2.0 的择时收益也是假的

**这份指南已经错了两次，第三次必须说清楚。**

| 版本 | 当时说的 | 后来发现 |
|---|---|---|
| v1.0 | 个股动量 +4193%，能做 | ❌ 换到全市场变成 **-70.1%** |
| v2.0 | ETF 择时 +149.92%，能做 | ❌ **有未来函数，真实只有 +27.4%** |
| **v3.0** | 见下 | — |

### 这次错在哪

回测代码是这一行：

```python
strategy_return = np.where(held, market_return, 0.0)
```

`held` 是**用当天收盘价**算出的 10 日均值判断的，然后**当天**就吃当天的收益。

**这在现实中做不到**——10 日均值要用当天收盘价才能算出来，你只有**收盘之后**才知道信号。但回测假设你"当天收盘前就知道，并且按收盘价成交"。

这是典型的**未来函数（look-ahead bias）**。

### 修正后的真实结果

把执行方式改成「T 日收盘后看信号 → T+1 开盘执行」：

| 执行方式 | 累计收益 | 年化 | 最大回撤 | 夏普 | 切换次数 |
|---|---|---|---|---|---|
| 买入持有（全市场等权） | **+22.9%** | +11.1% | -26.4% | 0.57 | — |
| A) 当日收盘执行（原回测，**有未来函数**） | **+149.9%** | +60.1% | -7.4% | 3.51 | 56 |
| **B) 次日开盘执行（你能做到的）** | **+27.4%** | +13.3% | **-16.5%** | **0.91** | 56 |
| C) 次日收盘执行（最保守） | +29.1% | +14.0% | -12.1% | 0.97 | 56 |

**虚高 122.5pp。**

### 更严峻的：换 20 组参数，只有 4 组赢

- **跑赢买入持有：4/20 组**

### 所以现在到底能用什么

**诚实的答案：择时不能提高收益，只能降低波动。**

| 你想要的 | 择时能做到吗 |
|---|---|
| 提高收益 | ❌ 不能（+27.4% vs +22.9%，20组里只有4组赢） |
| 降低回撤 | ✅ 能（-16.5% vs -26.4%，改善 10pp） |
| 提高夏普 | ✅ 能（0.91 vs 0.57） |

**如果你能接受"收益略低但回撤小得多"，择时还有用。如果你只想要收益，那不如直接买入持有。**

## 第一部分：ETF 择时（降波动工具，不是赚钱工具）

### 1.1 它做什么

每天**收盘后**判断：明天该持有沪深300ETF（510300），还是空仓拿现金。

规则只有一条：

```
大盘（全市场等权）最近 10 个交易日的平均日收益
  ≥ 0  →  HOLD（持有 510300）
  < 0  →  CASH（卖出，空仓）
```

### 1.2 ⭐ 执行时点（这是最重要的一节）

> **这是船长问的问题**：*"ETF买入卖出按开盘价还是收盘价？给了卖出信号，是第二天开盘卖吗？"*

**对，就是次日开盘执行。** 具体流程：

| 时间 | 你要做什么 |
|---|---|
| **T 日 15:00 收盘后** | 跑脚本，看信号 |
| **T 日晚上** | 定好明天的操作（买 / 卖 / 不动），挂好条件单或写好备忘 |
| **T+1 日 9:30 开盘** | 按信号执行：HOLD→买入或继续持有；CASH→卖出 |
| **T+1 日全天** | 什么都不做，不看盘 |
| **T+1 日 15:00 收盘后** | 再跑一次脚本，看新信号 |

**为什么必须次日开盘，不能当天收盘：**

`大盘10日均收益` 需要**当天收盘价**才能算出来。15:00 收盘的那一刻你才拿到数据，此时市场已经关闭，**当天无法成交**。所以最早只能 T+1 开盘。

**这里有个重要提醒**：如果你的券商支持14:57 集合竞价，理论上可以在 14:57 用"当日约 14:55 的价格"估算信号并挂单，但**这是近似，会有误差**。不建议，除非你能接受偶尔判断错。

### 1.3 真实回测效果（次日开盘执行，含 ETF 成本）

| 方案 | 累计收益 | 年化 | 最大回撤 | 夏普 |
|---|---|---|---|---|
| 买入持有 | **+22.9%** | +11.1% | -26.4% | 0.57 |
| **择时（次日开盘，最真实）** | **+27.4%** | +13.3% | **-16.5%** | **0.91** |
| 择时（次日收盘，最保守） | +29.1% | +14.0% | -12.1% | 0.97 |

分年度（默认参数）：

| 年份 | 买入持有 | 择时 | 差额 |
|---|---|---|---|
| 2024（10月起） | +0.1% | +10.1% | **+10.0pp** |
| 2025 | +35.2% | +25.0% | **-10.2pp** |
| 2026 | -17.6% | -8.9% | **+8.7pp** |

**规律很清楚：跌的年份择时赢（2024、2026），涨的年份择时输（2025）。**

### 1.7 仓位建议（已按真实收益调整）

因为真实收益只比买入持有高 4.5pp（不是原来的 +127pp），建议**大幅降低期望**：

| 阶段 | 仓位 | 目标 |
|---|---|---|
| 头 1 个月 | 20% | 确认自己能执行（不是确认能赚钱） |
| 1-3 个月 | 30-50% | 接受"涨的时候会跑输" |
| 3 个月后 | 最多 50% | **不建议全仓**，因为收益优势很小 |

**如果你只关心收益、不关心回撤，不要用择时，直接买入持有。**

### 1.8 关于"频繁切换"——这是常态，不是异常

> 钳星实际交易后提出的问题：*"提示 HOLD 买入，等两天提示 CASH 亏本卖出，又过两天提示 HOLD 买入，过几天又 CASH。"*

**这是正常的，回测里也是这样。** 实测数据（475 个交易日）：

| 指标 | 数值 |
|---|---|
| 信号切换总次数 | **56 次** |
| 平均每几天切换 | **8.5 个交易日** |
| 约每年切换 | **28.8 次** |
| HOLD 段中位持续时间 | **6 天** |
| CASH 段中位持续时间 | **3 天** |
| **只持续 1-3 天的"短命"区间** | **27 段 / 57 段 = 47.4%** |

**接近一半的信号段活不过 3 天。** 最近 10 次切换：

```
2026-07-31  买入(HOLD)   大盘10日均=+0.158%
2026-08-24  卖出(CASH)   大盘10日均=-0.238%
2026-08-27  买入(HOLD)   大盘10日均=+0.078%   ← 3天后买回
2026-08-31  卖出(CASH)   大盘10日均=-0.004%   ← 隔4天又卖
2026-09-01  买入(HOLD)   大盘10日均=+0.051%   ← 隔天买回（最打脸）
2026-09-11  卖出(CASH)   大盘10日均=-0.228%
2026-09-21  买入(HOLD)   大盘10日均=+0.096%
2026-10-08  卖出(CASH)   大盘10日均=-0.023%
2026-10-09  买入(HOLD)   大盘10日均=+0.039%   ← 隔天买回
2026-10-12  卖出(CASH)   大盘10日均=-0.266%   ← 3天后又卖
```

#### 成本测试（次日开盘执行）

| 单边成本 | 累计收益 | 年化 |
|---|---|---|
| 0%（理论值，次日开盘） | +31.0% | +14.9% |
| 0.03% | +28.8% | +13.9% |
| **0.05%（ETF 实际）** | **+27.4%** | **+13.3%** |
| 0.10% | +23.9% | +11.6% |

**56 次切换的成本拖累约 3.6pp。**

#### 心态上怎么接受

1. **把"切换"当成策略的一部分，不是失误。** 一年 28.8 次切换 = 平均每 8.5 天动一次。
2. **只在收盘后看信号，盘中不看。** 盘中看到跌会忍不住手动干预。
3. **记账按"年"看，不按"笔"看。** 单笔"打脸"亏损没有意义。
4. **如果实在受不了抖动**，CASH 时卖一半而不是全卖。抖动损失减半，但躲大跌效果也减半。

## 第二部分：个股动量 —— 已证伪，不要用

### 2.1 研究报告曾经说什么

用的股票池：`historical_daily` 里 **277 只行业股**（家电/农业/电力/旅游/酒店），2019-2026 共 8 年。

| 方案 | 累计收益 | 夏普 |
|---|---|---|
| 只有择时（买ETF） | +1209.8% | — |
| 择时 + 动量（理想） | +4193.2% | 3.25 |
| 择时 + 动量（含涨停过滤） | +1108% | — |
| 择时 + 动量（含涨停过滤 + 0.3%成本） | +664.6% | 2.33 |
| **纯动量（不加择时，独立贡献测试）** | **+542.5%** | — |

当时看起来动量是"真正正交的维度"，因为即使不加择时也有 +465pp 超额。

### 2.2 为什么这个结论是错的

三个致命问题，任何一个都足以推翻结论：

| 问题 | 说明 |
|---|---|
| **股票池选择偏差** | 277 只行业股是研究日历因子时挑出来的行业（家电/农业/电力/旅游）。这些行业 2019-2026 恰好各有强周期行情，选中的概率本身被后验知识污染了 |
| **幸存者偏差** | 277 只是**现在还在交易**的股票。同期退市、ST、暴雷的没进池子 |
| **样本外太短** | "样本外夏普 3.45"只有 2024-26 两年，且是回测 |

### 2.3 补验证：全市场 5700 只，2 年数据

我们写了一个新脚本直接验证 —— **同样的策略，只把股票池换成全市场**：

```powershell
cd d:\qcr\Stock\stock_analysis_system
.venv\Scripts\python.exe scripts\validate_full_market_momentum.py
```

**实测结果（478 个交易日，2024-10 ~ 2026-10，含单边 0.15% 成本）**：

| 方案 | 累计收益 | 年化 | 最大回撤 | 夏普 |
|---|---|---|---|---|
| 买入持有（全市场等权） | **+18.9%** | +9.3% | -23.8% | 0.49 |
| 纯动量（无择时） | **-70.1%** | -46.0% | -71.8% | -1.00 |
| 纯动量 + 涨停过滤 | **-85.4%** | -62.5% | -85.8% | -1.82 |
| 择时 + 动量 | **-47.0%** | -27.7% | -54.0% | -0.67 |
| 择时 + 动量 + 涨停过滤 | **-70.7%** | -46.6% | -70.8% | -1.59 |

**结论：全市场动量是明确的负向效应。不但不赚，还比买入持有差 89pp。加上涨停过滤后更差（-85.4%）—— 这是反直觉但合理的：涨停过滤剔掉的恰恰是最强的那批，剩下的动量股质量更烂。**

> ⚠️ **数据坑提醒**：第一版补验证时得出的是 -21.2%，那个数字**不可信**。原因是 `stock_data` 的「成交额」字段在 2024-10-11 ~ 2026-03-31 之间**完全是空的（18 个月）**，而回测用"成交额 ≥ 1亿"做流动性过滤，导致前 18 个月全被过滤掉，实际只跑了最后 7 个月。修正方法：用「收盘价 × 成交量」补成交额（已核对单位 ratio = 1.0，即成交量单位是"股"，估算准确）。上表是修正后的完整 2 年结果。

### 2.4 为什么动量在 277 只里有效、在全市场无效

最可能的解释：**277 只行业股里的"动量"其实是行业景气周期的延续性**（家电补贴、猪周期、电力高股息），那是有基本面支撑的趋势。但全市场 5700 只里，20 日涨幅最高的那批，基本都是**短期炒作的小盘妖股**，涨完就崩。

实测全市场动量清单（2026-08-20）：
```
605179  一鸣食品   +154.0%
002827  高争民爆   +127.0%
603221  爱丽家居   +124.7%
003032  传智教育   +113.4%   （当天 -10.02%）
```

这些不是能拿住的标的。

### 2.5 所以 `daily_momentum_signal.py` 还要不要用

**不要用来真金白银下单。** 但可以留着做两件事：

1. **看市场情绪** —— 如果动量清单里全是 ST、妖股、涨停，说明市场在炒垃圾，这本身是"该空仓"的另一个佐证
2. **学习用** —— 用 `--as-of` 复盘，对比当时清单和之后走势

如果你就是想试试水：

```powershell

.venv\Scripts\python.exe scripts\daily_momentum_signal.py --source historical_daily --max-picks 10
```

但要清楚：**这是在赌，不是在执行验证过的策略。**

## 第四部分：什么不要做（实验否掉的清单）

这些我们都认真试过，全部失败。写在这里是为了避免重复踩坑。

| 别做的事 | 为什么不行 | 证据 |
|---|---|---|
| **用模型预测个股短期涨跌** | micro/large 模型输出塌缩，AUC 0.435（比随机差） | 五轮实验全部失败，全市场71万行训练也一样 |
| **反向使用模型信号** | 以为反着用能赚，其实是模型输出标准差只有 1e-6，纯噪声 | signal_score 极差 1e-6 |
| **用日历效应做交易** | 旅游×国庆前8天看着有 +5.48%，逐年分解后 5/7 年是负的 | `CALENDAR_FACTOR_REPORT.md` |
| **用台风模型选股** | O 值 Pearson +0.0014（≈0），persistence_prob Spearman **-0.163（负相关）** | `TYPHOON_BACKTEST_NOTE.md` |
| **用强化学习调仓位** | 两次都退化成"恒定50%仓位"，策略没学到东西 | 见下节根因 |
| **跟着情绪操作** | 亏损后仓位降到 14%，盈利后升到 64% —— 典型的高买低卖 | +95.4% vs 规则 +822.4% |
| **择时 + 波动率筛选叠加** | 以为是协同，其实是重叠（择时已经间接剔掉了高波风险） | BOTH +1149% < TIME +1185.9%，只 3/8 年胜 |
| **个股动量选股** | 277只行业股里 +542%，换到全市场5700只变成 **-70.1%**，比买入持有还差 89pp | `validate_full_market_momentum.py` |

### RL 为什么失败（根因）

1. **奖励函数期望≈0**：`excess = position × r - r`，在随机行情下期望接近 0，梯度信号消失
2. **信用分配无解**：单资产日频决策，说不清"今天涨了是因为昨天加仓对，还是运气好"
3. **样本太少**：8 年只有 2000 个交易日，RL 需要的是百万级交互

**结论：日频单资产的仓位决策，不适合用 RL。** 这不是实现问题，是问题本身不适定。

## 第五部分：如果信号和你的直觉冲突怎么办

会冲突的，而且经常冲突。这时记住几个原则：

1. **信号说 CASH 但你觉得会涨** → 按信号走。理由：择时的价值不在判断对错，在于**错得便宜**。你踏空一次小涨，比躲过一次大跌划算。

2. **信号说 HOLD 但你觉得危险** → 按信号走，但可以减半仓。这是唯一的妥协空间。

3. **动量清单里的股票你觉得很垃圾** → 说明你的判断是对的。全市场动量已验证为负，那些涨得最凶的基本都是妖股。**别买。**

4. **连续错 3 次想放弃** → 这才是真正的考验。复盘数据说切换准确率只有 43%，意味着**连续错 3 次是常态，不是异常**。看暴跌躲避率（78%），别看准确率。

5. **某个月大幅亏损** → 先确认是不是执行偏差（比如该卖没卖），再看策略。别急着改规则。

## 最后一句

这套东西的价值不在于"能赚多少"，而在于**我们知道哪些做不到**。

这轮我们推翻了自己三次：

1. 动量 +4193% → 全市场换池后 **-70.1%**
2. 择时 +149.92% → 修未来函数后 **+27.4%**
3. 20 组参数里只有 **4 组** 跑赢买入持有

**但这一轮不是白跑的**——我们现在确切知道：

- 择时**能**把回撤从 -26.4% 降到 -16.5%（**改喖10pp**），夏普从 0.57 提0.91
- 择时**不能**提高收益（中位数跑输 9.1pp）
- 个股动量**完全没用**
- 短期反转微弱为正但不够成本

**所以现在你要做一个选择：**

| 你的目标 | 该做什么 |
|---|---|
| 想要收益最大化 | **直接买入持有**，不用择时 |
| 想要回撤小、能拿得住 | **用择时**，接受收益略低 |
| 想要高收益低回撤 | **做不到**（这就是本次研究最重要的结论） |

**执行方式必须记住：T 日收盘后看信号，T+1 日开盘执行。** 当天收盘执行是未来函数，做不到。

有任何问题，把输出贴出来，我们一起看。
