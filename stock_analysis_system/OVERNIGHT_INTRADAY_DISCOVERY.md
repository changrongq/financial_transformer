# 重大发现：A 股的「隔夜亏钱、日内赚钱」结构

> 2026-10-29
> 这是一次"从丑数字里挖出真相"的完整记录。

---

## 一、起点：一个难看的数字

在做 14 年 ETF 择时验证时，出现了这个对比：

| 执行方式 | 累计收益（510300，14.4年） |
|---|---|
| T 日收盘成交（**未来函数**） | +21604.7% |
| **T+1 开盘成交**（吃日内） | **+160.1%** |
| T+1 开盘买入但吃**全天**收益 | +73.3% |
| **T+1 收盘成交**（吃不到当天日内） | **+6.3%** |

**"T+1 收盘成交只剩 +6.3%" 这个丑数字，逼我们去问：为什么？**

---

## 二、答案：收益几乎全部来自「日内」

把 510300 的收益拆成两段（14.4 年，年化）：

| 时段 | 年化 |
|---|---|
| 全天（昨收 → 今收） | **+3.30%** |
| **隔夜（昨收 → 今开）** | **-10.76%** ❌ |
| **日内（今开 → 今收）** | **+15.92%** ✅ |

**隔夜是亏钱的，日内是赚钱的。**

这就完全解释了上面那张表：
- 吃日内（T+1开盘买）→ +160.1% ✅
- 吃不到日内（T+1收盘买）→ +6.3% ❌
- 吃全天（含隔夜）→ +73.3%（被隔夜拖累）

### 切换日的直接证据

| | 隔夜跳空 | 日内 | 全天 |
|---|---|---|---|
| **转空仓当日**（卖出） | -0.293% | -0.810% | **-1.098%** |
| **转持有当日**（买入） | +0.078% | +0.825% | **+0.904%** |

卖出那天真的在跌（全天 -1.098%），买入那天真的在涨（全天 +0.904%）。
**策略赚的是"避开隔夜下跌 + 捕捉日内上涨"的钱。**

## 四、诱人的陷阱：能不能"每天开盘买、收盘卖"？

既然日内赚 +15.92%/年，那每天开盘买、收盘卖不就行了？

**不行。因为成本。**

每天买卖 2 次，一年 488 次交易。测试结果（沪深300ETF，14.4 年）：

| 单边成本 | 累计收益 | 年化 | 结论 |
|---|---|---|---|
| 0%（理论） | +716.8% | +15.76% | 理论值 |
| 0.01% | +305.6% | +10.25% | |
| 0.02% | +101.4% | +5.00% | |
| **0.03%** | **-0.0%** | **-0.00%** | **归零** |
| 0.05% | -75.4% | -9.30% | 亏钱 |
| 0.10% | -99.3% | -28.96% | 惨亏 |

**成本临界点只有 0.032%（单边）。**

ETF 实际交易成本 0.03%~0.05%（含买卖价差+佣金），**正好卡在死亡线上**。

上证50ETF 的临界点好一些（0.048%），但同样危险。

## 五、正确的用法：不是每天交易，而是解释"为什么必须开盘执行"

| 方案 | 沪深300ETF | 上证50ETF |
|---|---|---|
| 买入持有 | +59.4%（年化 3.30%） | +214.9%（年化 5.76%） |
| 每天日内交易（万3成本） | **亏钱** | 边缘 |
| **择时（T+1开盘执行）** | **+160.1%（年化 6.89%）** | **+1000.1%（年化 12.42%）** |
| 择时最大回撤 | -26.5% | -35.3% |

**择时把交易次数从 488次/年 降到 34次/年，成本降低 14 倍，结果反而更赚。**

### 所以这个发现的实际价值

1. **解释了为什么必须 T+1 开盘执行** —— 拖到收盘就错过了日内段
2. **解释了为什么择时有效** —— 它同时避开了"隔夜下跌"和"持仓期的下跌"
3. **警告了一个诱惑** —— 别想着每天日内交易，成本会吃掉一切
4. **提供了一个优化方向** —— 如果能把成本压到 0.02% 以下，日内策略的空间会打开

## 六、为什么会这样？（机制解释）

**A 股特有的"隔夜负、日内正"可能来自：**

1. **隔夜情绪释放**：外盘、消息面在夜间发酵，次日开盘集中反映，容易低开
2. **尾盘资金行为**：国内资金习惯尾盘买入（怕隔夜风险），推高收盘价
3. **T+1 制度**：今天买入不能今天卖，所以想卖的人必须等到次日，压低开盘
4. **机构调仓习惯**：很多机构在收盘前执行，日内形成买压

> 这些解释未经严格验证，仅作参考。但**结构本身在 11 个标的上一致，说明背后有系统性原因。**

## 八、还没解决的问题

1. **机制未验证**：上面四条解释都是猜测，没做严谨检验
2. **分钟级数据缺失**：无法验证 9:30-9:35 那几分钟的具体价格（tushare 分钟线限速，且只到 2026-09）
3. **A 股之外是否成立**：没测美股/港股。如果它们也是"隔夜负、日内正"，那这个规律可能是全球性的，解释就不同了
4. **成本能否优化**：如果能拿到万1的成本（大资金/低佣券商），日内策略的空间会打开。但滑点很难控制

**最重要的悬念**：这个规律会不会消失？A 股在 2019、2023 已经有过例外（隔夜转正）。如果监管、交易制度或参与者结构改变，规律可能失效。
